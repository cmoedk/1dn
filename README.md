# One Dude Nation: The World Cup Quest — Issue Tracker

**This repository holds no source code.** It exists only to track bugs and ideas for
*One Dude Nation*, a browser-based, one-finger-control soccer game. 

## Filing a bug

Open the **[Issues](../../issues)** tab → **New issue** → **Bug report**, and fill in the form.

The two things that make a report fixable:

- **The build stamp.** It's on the splash screen, bottom-right: `v.1.0.0-beta.1` over `Build 2026-08-18-14:30`.
- **A backup file**, if the bug involves a saved run. In-game: **Settings → Backup** writes a single
  file holding your whole game — the run and its paused frame, your goals and their replays, History,
  Records and your settings. Attach it to the issue and the exact state can be reproduced.

If you can share the goal itself, the replay screen's **gear → Share Replay** copies a link that
carries the whole recording inside it. Paste that in.
